# short-animation-harness

JSON の台本から短いアニメーション動画を書き出す、**AI エージェント向けの最小のハーネス**です。
[Remotion](https://www.remotion.dev/) で描き、ffmpeg で音の大きさをそろえます。

中身はわざと最小限です (背景に絵を置いて動かす・文字と音を出す、だけ)。
跳ねる・回る・吹き出し・転換などの機能は入っていません。**作りたい動画に合わせて、エージェントが必要な機能をその都度足していく**前提の設計です。手順はエージェント向けの説明書 [`AGENTS.md`](AGENTS.md) にあります。

## できること

- **台本 → 動画**: 場面・役者・拍 (いつ・誰が・何をするか) を JSON で書くと、60fps の mp4 とサムネイルを書き出します。
- **検査**: 台本の誤り・役者のはみ出しを書き出す前に見つけ、拍ごとの時刻表を出します (`npm run check`)。
- **静止画で確認**: 拍ごとの静止画を一覧にします (`npm run stills`)。
- **音の大きさ**: 全体を -14 LUFS にそろえ、一部だけ大きすぎる所を自動で下げます (`npm run render`)。
- **見直し**: 書き出した動画をタイムコード付きのコマ一覧にして、エージェントが完成の前に通して見直します (`npm run review`)。
- **素材の登録**: `public/` の決まったフォルダに画像と音を置くだけで、台本から名前で呼べます (`npm run assets`)。

## 使い方

必要なもの: Node.js 20 以上、ffmpeg (ffprobe も)。

```sh
npm install
npm run setup        # フォント (OFL) を取ってきて、素材を登録する
```

あとは AI エージェント (Claude Code・Codex など) でこのリポジトリを開き、作りたい動画を伝えてください。
素材がまだ無ければ、どこに何を置けばよいかをエージェントが案内します。

自分で触るときは `AGENTS.md` の「コマンド」と `docs/episode-format.md` を見てください。

## 素材について

このリポジトリには画像・音の素材を同梱していません。使う素材の利用規約は各自で確かめてください。再配布が禁じられている素材は、公開リポジトリに commit しないでください。
